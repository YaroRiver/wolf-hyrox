## TUESDAY 1 SEPTEMBER — Full Hybrid Lower/Station Day + Row Calibration

**A. Running warm-up:** ~1.2km easy, then dynamic lower-body warm-up.

**B. Row 1000m — controlled race-execution baseline.** Warm-up: 8–10min easy row + 3 progressive 10-stroke builds. Main: 1000m at **RPE 7.5–8/10**, no opening sprint, no all-out final 100m, aim for even/slight negative split. Record total time, first 500m, second 500m, avg/500m, stroke rate, HR, RPE. Recover **8–10min** before lower work.

**C. Lower strength:**
1. Leg Extension — 62kg × 3×15, rest 60–75s
2. Leg Press — 80kg × 3×8, rest 2:00
3. Bulgarian Split Squat — 22.5+22.5kg × 3×8 each leg, rest 2:00
4. Walking Lunges — 28+28kg × 2×30m, controlled, no failure
5. Leg Curl — 54kg × 3×10, rest 90s

Rule: 2–3 reps in reserve — productive training, not grinding.

**D. Sled Push — maintenance:** 232kg × 3×20m, rest 60s. No load chase, no timing pressure, technically clean work.

**E. Sled Pull — first-set protocol:** 202kg × 3×20m, rest 2:00. Rope laid out identically before each set; find rhythm immediately rather than using set 1 to learn setup. Record all three times. **Score: Set 1 minus Set 3 — smaller is better.** Race-load validation at 153kg remains W38.

**F. Wall Balls:** 2×25 @9kg, rest 45s. Technique + breathing, relax arms during ball flight — no 100-rep benchmark, no time chase.

1. Rep 1 is not the fastest rep.

## SATURDAY 5 SEPTEMBER — Key Integration Session: Control Run → Lunges → Test Run

**Headline question: what do 100m of race-load lunges cost the next kilometre?**

Instead of removing training earlier in the week, the control is created **inside this session**.

**A. Warm-up:** 1.5km easy + dynamic hip/quad/ankle prep + 6–8 unloaded lunge steps + 2×20s relaxed strides if legs feel normal. Use the **same measured lane** as the W35 lunge baseline.

**B. Run 1km — CONTROL:** controlled sustainable HYROX run effort, no opening sprint, no sprint finish — run it as something reproducible. Record total time, HR avg/peak, cadence, power, RPE.

**C. Recovery:** 3–4min easy walk, standardised and recorded.

**D. Sandbag Lunges — 30kg × 100m**, same measured lane as W35. Record 0–50m, 50–100m, total, step count per 20m if practical, burn-onset point, posture/step-length change. **Do not chase W35's first-50m time of 1:39.54** — goal is a smoother first half, smaller second-half collapse, stronger total execution. W35 baseline for reference: 1:39.54 / 2:10.70 / 3:50.24 total, ~31% second-half drift.

**E. Transition:** 30–45s, timed exactly. No sitting — move directly to the run start.

**F. Run 1km — TEST:** same instruction as Run 1 — controlled sustainable HYROX effort, no sprint finish, do not force the first 200–250m. Record total time, HR avg/peak, cadence, power, RPE, quad/VMO/soleus/Achilles response.

**Saturday primary score: RUN DRIFT = Run 2 time − Run 1 time.** Smaller is better — this is the first formal within-session estimate of lunge→run cost.

Secondary scores: lunge total time, first-half vs second-half lunge drift, transition time, mechanical quality of Run 2.

**G. Cooldown:** ~1km easy. No extra benchmark work after the test.

**Running: ~4.5–5km.**
